# 🚀 Webcam Demo Local - Quickstart

## Chạy nhanh

```bash
cd ai\datn\script
run_demo_local.bat
```

## Phím tắt

- **R**: Start/Stop Recording
- **S**: Screenshot
- **Space**: Pause/Resume
- **Q**: Quit

## Kết quả

- Video recording: `demo_recordings/demo_YYYYMMDD_HHMMSS.mp4`
- Screenshots: `demo_recordings/screenshot_YYYYMMDD_HHMMSS.jpg`
- Statistics: Hiển thị trong console sau khi stop recording

## Cấu hình

Chỉnh settings trong `demo_config.py`:

- Webcam ID
- Resolution
- FPS
- Model paths

## Lưu ý

✅ Hoàn toàn offline (không cần backend/AI server)  
✅ Statistics giống hệt AI server  
✅ Lý tưởng cho demo khi mạng không ổn định
